# **IOTO，是如何受到《中庸》中「学问思辨行」影响的**

对我影响最大的知识管理思想的来源，不是现代的知识管理理论，也不是任何一款笔记软件。

而是《中庸》第二十篇中的一句话：

博学之，审问之，慎思之，明辨之，笃行之。

短短十几个字，却几乎概括了一个人学习和成长的全过程。

两千多年来，无数人都在研究这句话。

朱熹提出「先知后行」，王阳明提出「知行合一」。

这些解释都给了我很多启发。

但在真正理解这十几个字的时候，我始终有一个疑问没有解决。

**问、思、辨，到底有什么区别？**

如果只是把它们都理解成「思考」，那为什么孔子要把它们拆成三个步骤？

这个问题，我想了很久。

后来，我决定暂时放下各种注解，而是换一种方式重新理解它。

## 我引入了两个维度

我发现，所有学习活动，其实都可以放进两个维度中去观察。

一个是时间。

过去 → 现在 → 未来

另一个是空间。

他人 → 我 → 他人

于是，我画出了下面这张图。

![](https://wafer-1257318448.cos.ap-guangzhou.myqcloud.com/20260724050212.png)

有了这两个坐标之后，很多原来看起来差不多的概念，突然就变得清晰起来。

## **问，是为了理解别人**

学习，本质上是在获取别人已经形成的经验和知识。

这些知识，大多来自过去，也来自他人。

因此，当我们在学习过程中遇到疑问时，首先要做的，不是表达自己的观点，而是努力理解作者真正想表达什么。

所以，「问」的重点，并不是质疑。

而是追问。

不断追问，直到真正理解对方。

这时候，我们需要尽量站在作者的角度思考，而不是急着用自己的立场去评价。

只有这样，才能真正做到「审问」。

## **思，是让知识变成自己的**

当理解了别人之后，还远远没有结束。

真正重要的，是把这些知识放进自己的知识结构里。

它和我过去学过的内容有什么关系？

它会不会推翻我原来的认知？

它能不能解释我曾经遇到的问题？

这个过程，就是「思」。

它发生在自己的内部。

它既连接过去积累的经验，也决定未来能够提取什么。

因此，在整个学习过程中，我认为「思」是最核心的一步。

因为所有知识，最终都要经过这里，才能真正变成自己的。

## **辨，是为了未来的实践做判断**

很多人会把「辨」理解成分辨对错。

我现在更愿意把它理解成判断。

因为真正开始实践的时候，我们面对的不再是抽象的知识，而是具体的人、具体的事情、具体的场景。

同样的方法，对不同的人，可能完全不同。

同样的知识，在不同的时间，也可能需要不同的选择。

所以，「辨」不是继续理解知识。

而是在准备行动之前，根据未来的实际情况，做出判断。

因此，我认为：

问，是理解过去的别人。

思，是建构现在的自己。

辨，是面向未来的他人。

三者虽然都属于认知活动，却承担着完全不同的职责。

## **也正是在这里，我重新理解了知识管理**

当我重新理解了「学问思辨行」之后，一个新的问题又出现了。

知识管理，到底应该管理什么？

很多人理解的知识管理，是收集资料。

有人理解成整理笔记。

有人理解成建立知识库。

但我越来越觉得，这些都只是手段。

真正需要管理的，是整个价值流动的过程。

于是，我发现，「学问思辨行」其实天然对应着三个不同的价值阶段。

![](https://wafer-1257318448.cos.ap-guangzhou.myqcloud.com/20260724050231.png)

**学**，是在获取价值。

这是 Input。

我们从他人那里获得知识、经验和信息。

**问、思、辨**，虽然发生在大脑里，却不断产生新的理解、新的联系和新的判断。

如果这些认知始终停留在脑海里，它们就很容易消失。

所以，我们需要把这些思考记录下来。

不是为了发表。

不是为了分享。

而是为了让认知从第一大脑进入第二大脑。

这，就是 Output。

它真正输出的，不是文章，也不是视频。

而是**认知的显化**。

最后，当这些知识真正进入实践，为别人创造价值的时候，就是 Outcome。

它们分别对应着价值流动过程中三个完全不同的阶段：

- Input：获取价值。
- Output：显化价值。
- Outcome：创造价值。

这，也是 IOTO 最初的理论起点。

## **一个双向循环，而不是一条流水线**

很多人会把「学问思辨行」理解成一条线性的流程。

学完，再问。

问完，再思。

思完，再辨。

辨完，再行。

但真正的学习，并不会停留在这里。

实践以后，我们会产生新的问题。

新的问题，又会带来新的学习。

于是，我把它画成了一个不断循环的无限模型。

![](https://wafer-1257318448.cos.ap-guangzhou.myqcloud.com/20260724050253.png)

在这个模型中。

从「学」出发，形成的是：

**学 → 问 → 思 → 辨 → 行 → 思 → 学**

而从「行」出发，则形成：

**行 → 辨 → 思 → 问 → 学 → 思 → 行**

左侧，是认知。

右侧，是实践。

两者通过「思」不断连接，也不断循环。

在这个循环里，Input、Output 和 Outcome 三个阶段始终存在，并不断推动价值向前流动。

## **写在最后**

很多人学习知识管理，第一件事就是寻找更好的工具。

但我越来越觉得，工具只是最后一步。

真正重要的是，先弄清楚价值究竟是如何流动的。

哪些属于获取价值。

哪些属于沉淀价值。

哪些属于创造价值。

当这三个阶段真正区分开以后，知识管理才真正有了明确的对象。

而 IOTO，也正是在这样的思考过程中，一点一点形成的。
